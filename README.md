# My Personal Web Page

A place where I share my passion for IT, AI, and helping to solve problems with effective technological solutions.

## To use this template
* **1. Clone the repo** 

```console
git clone https://github.com/pablocevalenzuela/pablocevalenzuela.github.io.git
```

* **2. Install dependencies** 

```console
brew install node
```

* **3. Run the web page** 

```console
cd pablocevalenzuela
npm run dev
```
